# smart-panel

The electronics panel of the robot: the enclosure that holds the Jetson, the stepper drivers, the VESCs and the other
boards, plus the wiring between them.

| Folder | What |
| --- | --- |
| [`panel`](panel) | OpenSCAD layout study: does everything fit in the 600 x 600 x 200 mm panel, and where does it go? |
| [`wiring`](wiring) | Wiring of the panel (not started) |

All dimensions are in millimetres.
