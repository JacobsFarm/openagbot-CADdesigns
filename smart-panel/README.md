# smart-panel

The electronics panel of the robot, built in a VEVOR NEMA steel enclosure of 24 x 24 x 8 inch
(60 x 60 x 20 cm, NEMA 4X, IP66, with mounting plate; see [`panel`](panel/README.md#the-panel)): the enclosure that holds the Jetson, the stepper drivers, the VESCs and the other
boards, plus the wiring between them.

| Folder | What |
| --- | --- |
| [`panel`](panel) | OpenSCAD layout study: does everything fit in the panel (inside 550 x 565 mm), and where does it go? |
| [`wiring`](wiring) | Wiring of the panel (not started) |

All dimensions are in millimetres.
